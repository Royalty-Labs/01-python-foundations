## Getting Started

### Prerequisites

Before running the projects, install:

- Python 3.
- Git.
- A code editor such as VS Code.

Verify your Python installation:

```bash
python --version
```

Depending on your system, you may need to use `python3` instead.

### Clone the Repository

```bash
git clone <YOUR-REPOSITORY-URL>
```

Navigate into the cloned repository:

```bash
cd 01-python-foundations
```

Replace `<YOUR-REPOSITORY-URL>` with the actual GitHub repository URL.

### Run a Project

Navigate to the directory containing the project you want to run, then execute its Python entry-point file.

For example:

```bash
python main.py
```

Replace `main.py` with the actual filename used by that project.

Some projects may require additional dependencies or environment variables. Follow any instructions provided in the relevant project directory.

## Working with AI Projects

Projects that communicate with external AI services may require API credentials.

For these projects:

- Store secret keys in environment variables or a local `.env` file.
- Never commit API keys or other credentials to GitHub.
- Use a `.gitignore` file to exclude sensitive local configuration.
- Check the relevant service's documentation for its current API requirements.
- Handle network errors and unsuccessful API requests appropriately.

Not every project in this repository requires an AI service.
